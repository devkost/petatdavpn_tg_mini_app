**1.1.** Настоящее Пользовательское соглашение (далее — «Соглашение») определяет порядок предоставления и использования услуг Сервиса.

**1.3.** Для использования Сервиса Пользователю может потребоваться Telegram-аккаунт и/или иные данные, необходимые для предоставления доступа.

**2.2.** Конкретный набор доступных функций зависит от выбранного тарифного плана.

**2.3.** Информация о стоимости, продолжительности подписки, доступных тарифах и иных существенных условиях предоставляется Пользователю до момента оплаты.

**2.4.** Сервис может предоставлять доступ к различным техническим конфигурациям, серверам и функциям. Их перечень может изменяться в зависимости от технических возможностей и текущего состояния инфраструктуры.
